 # 🧬 LifeLens AI

**LifeLens AI** is an AI-powered personal health and wellness platform developed using **Python**, **Streamlit**, and **Machine Learning**. It helps users monitor their lifestyle, predict wellness status, and securely manage emergency medical information.

## 🌐 Live Demo

https://lifelens-ai-f2gkuvafk4eyakunfyxy3n.streamlit.app/

## ✨ Features

* AI Wellness Prediction
* Health Analytics Dashboard
* AI Health Assistant
* Emergency Medical Vault
* Interactive Data Visualization
* Modern and Responsive UI

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* Scikit-learn
* Machine Learning

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run a.py
```
